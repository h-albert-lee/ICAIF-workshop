\section{Archived-response diagnostics (provisional)}
\label{app:diagnostics}

The following snapshot audits four completed conditions, each with 1,440 documents, 13,723 requests and 218,664 gold spans. Every archived strict metric and failure record was replayed. Native token-count files and the underlying cohort gate have not yet been independently verified, so these values are not a finalized cross-model leaderboard. Pilot-only uploads are excluded. The diagnostic rules were selected after inspecting strict failures and are explicitly post-hoc.

Valid items can be recovered from rejected requests, but gains also depend on added true and false positives; this is not a causal separation of format and recognition ability. Invalid top-level JSON and terminal failures remain empty, with all gold false negatives. Unparseable outputs have unknown item counts, so no item-count penalty is invented. Character scores weight characters rather than mentions and need not exceed exact F1. Strict results remain the primary protocol. Model settings and prompts are not tuned from these outcomes.
